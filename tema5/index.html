💻 Códigos: Servidores Concurrentes (Multithreading)

Consideraciones de diseño para ServidorMultiThread.java:
  • La clase hereda de Thread, por lo que cada instancia es un hilo.
  • La creación de cada objeto hilo se realiza después de la llamada a accept().
  • La clase posee un método run() con la lógica concurrente.
  • ServerSocket y Socket pasan a ser variables al nivel de la clase.
  • ServerSocket es estática (mismo valor para todos los hilos).
  • Socket es de instancia (valor independiente para cada hilo).
  • ServidorMultiThread.java Java Crea un hilo independiente por cada cliente que se conecta (Servidor Concurrente).
  • ClienteMultiThread.java Java Idéntico a Cliente03. La lógica multihilo recae exclusivamente en el servidor.
