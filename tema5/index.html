💻 Códigos: El servidor genera la llave cada vez que se inicia

  • ServidorCifrado01.java Java Este servidor genera el objeto Key y lo guarda en un archivo llave.ser para que, posteriormente, el cliente lea el objeto de ese archivo y de esa manera Cliente y Servidor utilicen la misma llave para cifrar/descrifrar. En este caso, el cliente envía un mensaje cifrado y termina. El servidor recibe el mensaje cifrado y lo descifra..
  • ClienteCifrado01.java Java Este es el cliente, lee un mensaje del teclado, lo cifra y lo envía al servidor.

💻 Códigos: La llave se genera previamente, para que tanto Cliente como Servidor la utilicen para encriptar y desencriptar

  • GeneradorLlave.java Java Este programa debe ejecutarse antes del ServidorCifrado02 porque genera el objeto Key y lo guarda en un archivo llave.ser, de esta manera el Servidor no debe crear la llave cada vez que se ejecuta..
  • llave.ser Nuestra llave que utilizarán tanto cliente como servidor para encriptar/desencriptar.
  • ServidorCifrado02.java Java Este servidor recibe el mensaje cifrado del cliente, lo desencripta y muestra en pantalla. Posteriormente cierra la conexión del cliente y se pone en espera de otro cliente. Se termina con Control-C.
  • ClienteCifrado02.java Java Lee la llave del archivo llave.ser, lee un mensaje del teclado, lo cifra y lo envía al servidor.
