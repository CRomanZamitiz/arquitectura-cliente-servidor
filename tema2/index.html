  • Gráfico: fork(), exec() y wait() Muestra gráficamente el comportamiento de estas funciones.

💻 Códigos: Señales

  • programa04_signal_caso1.c C Caso 1: Ignorar la señal con signal(SIGINT, SIG_IGN).
  • programa05_signal_caso2_v1.c C Caso 2 (v1): Manejar la señal con tratamiento propio; el proceso continúa.
  • programa05_signal_caso2_v2.c C Caso 2 (v2): Manejar la señal con tratamiento propio y terminar el proceso.

💻 Códigos: Procesos en Background y Zombies

  • programa07_background.c C Simula procesamiento para probar el envío a background con Ctrl+Z, el comando bg o utilizando &.
  • programa08_zombie.c C Genera un proceso zombie durante 60 segundos debido a la encolación de SIGCHLD.
  • programa09_nozombie_v1.c C Solución 1 a procesos zombie: Ignorar la señal SIGCHLD o SIGCLD.
  • programa09_nozombie_v2.c C Solución 2 a procesos zombie: Implementar una función manejadora de señales para SIGCHLD.

💻 Códigos: Señal SIGKILL, kill() y abort()

  • programa10_SIGKILL.c C Ejercicio para probar el envío de señales desde terminal con kill -SIGXXX PID.
  • programa11_kill1.c C El padre termina fulminantemente al hijo utilizando kill(pid, SIGKILL).
  • programa12_kill2.c C Se crean 2 hijos; el padre elimina al hijo 2 y luego llama a exit(0).
  • programa13_abort.c C Uso de la función abort() para enviar la señal SIGABRT al propio proceso.
